# Snort IDS - Projet INF-376

Système de Détection d'Intrusion avec Dashboard Temps Réel

# Fonctionnalités
- Détection d'intrusion en temps réel (TCP/UDP/ICMP)
- Dashboard web interactif avec graphiques
- Courbe d'évolution des alertes
- Histogramme par protocole
- Camembert de répartition
- Radar d'activité réseau
- Blocage de trafic (mode inline)
- Scripts de démarrage/arrêt automatiques
